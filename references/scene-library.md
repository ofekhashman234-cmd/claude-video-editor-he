# ספריית הסצנות: סרטון מרשימה, בלי קוד

המנוע: `assets/scenes/reel.html`. מעתיקים אותו לתיקיית הפרויקט (תמונות נטענות יחסית אליו), כותבים `scenes.json`, ומרנדרים:
```
cp <SKILL>/assets/scenes/reel.html .
"$PY" <SKILL>/assets/compose.py --duration <סכום ה-dur> --overlay reel.html --data scenes.json --preview --out out/preview.mp4
```
- **סרטון בלי פנים:** בלי `--video` (רקע המותג). קריינות: `--audio voice.m4a`.
- **מעל צילום:** `"transparent": true` ב-JSON, ו-`--video footage.mp4`. כך הסצנות הן שכבות מעל הצילום (כרטיסים, רשימות, ספירה), בלי רקע.
- נבדק ב-25.10.2026: 20 שניות ו-6 סצנות מרונדרות בכדקה (טיוטה).

## מבנה
```json
{
  "brand": {"bg":"#110E2B","accent":"#FF6B2C","line":"#8C7CFF","name":"השם שלך","colors":["#FF6B2C","#6A4BFF","#1F6FE0","#0E8A47"]},
  "transparent": false,
  "scenes": [ {"type":"...", "dur": 3.0, "caption": {"text":"...", "key":"מילה"}, ...} ]
}
```
לכל סצנה אפשר להוסיף `caption`: גלולה לבנה בתחתית, עם המילה שב-key צבועה. אם אחרי הבדיקה צריך להזיז אותה, `captionTop` (ברירת מחדל 1500).

## הסוגים
| type | מה רואים | שדות | אורך מומלץ |
|---|---|---|---|
| `hook` | פתיח: צ'יפ קטן ואז כותרת ענק מילה אחרי מילה, מילת המפתח על בלוק צבע | `small`, `big`, `key`, `size` (ברירת מחדל 118; 3 מילים בשורה) | 2.5 עד 3 |
| `statement` | משפט חזק במרכז, מילה אחרי מילה, ומשפט משנה | `text`, `key`, `sub`, `size`, `top` | 2 עד 3 |
| `list` | כותרת ורשימה ממוספרת שנכנסת פריט אחרי פריט (ריבוע צבעוני לכל פריט) | `title`, `key`, `items[]`, `numbered` (false = וי), `step` | 0.8 לפריט + 1 |
| `chat` | צ'אט: בקשה מוקלדת ותשובה זורמת. `good:false` = "בלי" באדום, true = "עם" בירוק | `label`, `good`, `user`, `ai`, `code` (תשובה כקוד) | 4 עד 4.5 |
| `flow` | שלבים מחוברים בקו זוהר, נדלקים אחד אחרי השני | `steps[]` (עד 5) | 0.8 לשלב + 1 |
| `screen` | צילום מסך בתוך טלפון או חלון דפדפן. כמה תמונות מחליקות אחת אחרי השנייה | `img` (נתיב או רשימה), `frame` ("phone"/"window"), `title`, `key`, `scroll` (פיקסלים) | 2.5 עד 4 |
| `counter` | מספר ענק שרץ ונצבע בצבע ההדגשה בסוף, עם הסבר | `from`, `to`, `prefix`, `suffix`, `label` | 2 עד 2.5 |
| `compare` | שתי עמודות: ימין אדום (✕) ושמאל ירוק (✓), השמאלית נכנסת אחרי `delay` | `right:{title,items}`, `left:{title,items}`, `delay` | 4 |
| `cta` | "כתבו / [מילה על בלוק] / בתגובה 👇" ושורת משנה. גודל המילה מתאים את עצמו לאורכה | `before`, `word`, `after`, `sub` | 2.5 עד 3 |

### סוגים נוספים (סבב 2)
| type | מה רואים | שדות | אורך מומלץ |
|---|---|---|---|
| `bigword` | מילה או שתיים בכל פעם, ענק, בלי מסגרת (בני פרבר) | `words[]` או `text`, `key`, `each`, `size`, `top` | 0.35 עד 0.5 למילה |
| `toolbox` | "ארגז הכלים": גריד של אייקונים, והכלי המדובר מקבל מסגרת ומתנפח | `title`, `items:[{name,icon,color}]`, `highlight` (אינדקס), `hlAt` | 3 |
| `terminal` | חלון טרמינל שמקליד שורות. `>` = פקודה (צבע הדגשה), `✓` = הצלחה (ירוק) | `lines[]`, `cps` | 3 עד 4 |
| `timeline` | ציר עריכה: קליפים, גל קול, ראש ניגון ומספריים, וקליפים שנחתכים | `clips`, `cuts[]` (אינדקסים) | 2.5 עד 3 |
| `bars` | עמודות שעולות עם מספרים רצים ולוגו/אימוג'י, וכתר למנצח | `items:[{label,value,logo,win}]`, `prefix`, `suffix`, `crown` | 3 עד 3.5 |
| `quote` | כרטיס ציטוט לבן עם מילים צבועות, ואימוג'י שקופץ | `text`, `key` (כמה מילים מופרדות ברווח), `emoji`, `emojiTop`, `emojiLeft` | 2.5 |
| `news` | כרטיס כתבה מוטה עם מקור ותאריך, וזום איטי. **רק כתבה אמיתית** | `source`, `date`, `headline`, `body` | 2.5 עד 3 |
| `sticker` | תמונה שלך בעיגול עם מסגרת לבנה, תגית, וגל קול שזז | `img`, `label` | 2.5 |
| `commentcta` | שאלה, תיבת תגובה שמוקלד בה, ותגית "שלחתי לך בפרטי" | `title`, `key`, `word`, `reply` | 3 |
| `lowerthird` | תווית שם ותפקיד שנכנסת מהצד (מעל צילום, `transparent:true`) | `name`, `title` | 2.5 |

**שדה לכל סצנה:** `stamp` = חותמת מוטה בצבע ההדגשה ("בלי פרימייר"), עם `stampAt` (שניות) ו-`stampTop`.

## ערכות נושא וכתוביות
`"theme"` ברמת הסרטון:
| theme | איך זה נראה | כתוביות ברירת מחדל |
|---|---|---|
| `brand` (ברירת מחדל) | נייבי עם קווים גליים וזוהר סגול-כתום (ברירת המחדל) | pill |
| `cinematic` | שחור עם זוהר אדום מהרצפה (בני פרבר, Claude Code) | bold (לבן ענק, מילה אדומה, בלי מסגרת) |
| `doc` | חום כהה וחם, כתום (בני, "דוקו") | bold |
| `light` | בהיר, ממשק לבן (עדן הוותיק) | bar (פס כהה) |
`"captionStyle": "pill" | "bold" | "bar"` דורס את ברירת המחדל. `brand.accent` דורס את צבע ההדגשה של ערכת הנושא.

## שכבות מאחורי האדם (`overlays/behind.html` + `compose.py --behind`)
`DATA.behind = [...]`:
- `{kind:"wall", text, key, s, e, y, size}`: טקסט על הקיר
- `{kind:"mag", text, s, e, y, size, sub}`: שם מגזין
- `{kind:"notes", items[], s, e, every}`: פתקים
- `{kind:"logos", items[], s, e}`: לוגואים שעולים

compose מפריד את האדם אוטומטית בטווח המרונדר (`--person` = שכבה מוכנה). זום לא נתמך יחד עם שכבה אחורית.

## חוקים
- **מספרים אמיתיים בלבד** ב-counter ובכל טקסט. מספר שלא אומת לא עולה למסך (ספירה של פריטים מהסרטון עצמו זה בסדר).
- **מקסימום 3 עד 4 שניות לסצנה,** חוץ מ-chat ורשימה ארוכה.
- **מבנה מומלץ לרילס של 15 עד 25 שניות:** hook ← (list | compare | chat) ← flow או screen ← counter (רשות) ← cta.
- **סצנה חדשה שאין בספרייה:** מוסיפים פונקציה ל-`BUILD` ב-reel.html, שמחזירה `u => {...}` (u הוא הזמן מתחילת הסצנה, וכל מצב מחושב מ-u בלבד), ומתעדים אותה כאן.
- דוגמאות עובדות: `assets/examples/*.scenes.json`.
