## ו. שילובים מוכנים ("מתכונים")
המשתמש יכול לבחור שילוב שלם במקום סגנון בודד. בלוח מציגים 2 עד 3 שילובים, ולא רק סגנונות.
| שילוב | ההשראה | מה בו | מתאים ל |
|---|---|---|---|
| **"המסביר"** | עדן ואיילון היום | פתיח קינטי ← מסך מפוצל עם איורי קו ← גלולה + זום ← כתבה מוטה ← "כתבו X" | הסבר על כלי או חדשה, עם פנים |
| **"הבית (המותג שלך)"** | המותג | נייבי, פתיח עם בלוק כתום, רשימה או השוואה, תהליך, מונה, הנעה לפעולה | בלי פנים, ערך לבעלי עסקים |
| **"סייבר אדום"** | בני עם Claude Code | סינמטי: bigword ← ארגז כלים ← טרמינל ← טיימליין + חותמת ← סטיקר + גל ← תיבת תגובה | "איך בניתי את זה", בלי פנים |
| **"דוקו"** | בני, אנתרופיק | חום כהה: שנה ענקית ← עמודות עם כתר ← כתבה ← תווית שם ← מילים ענקיות | סיפור עם מספרים או השוואה |
| **"רחוב"** | בני הוותיק | החלפת רקע (מטושטש) + מילים ענקיות + אייקון אפליקציה + PiP | דיבור למצלמה מהיר, עם פנים |
| **"פתיח וואו + נקי"** | Brain | 2 שניות של טקסט מאחורי הראש או מגזין ← הסרטון בגלולה + זום | כל דיבור למצלמה, כשרוצים רגע אחד שעוצר |
| **"ציטוט ← מפוצל"** | עדן | כרטיס ציטוט + אימוג'י ← מסך מפוצל עם כתבות וסימונים | סיפור או חדשה עם מקור |

## איך בוחרים 3 עד 5 ללוח
- **תמיד:** אחד מקבוצה א' כבסיס (בדרך כלל pill או split), ו-hook לפתיח.
- **סרטון בלי פנים:** motion ו-screen במקום split.
- **תוכן על AI:** chat או "השוואה".
- **רגע וואו אחד** מקבוצה ג' או ה', אם יש לו משפט שמתאים לו בדיוק (HyperFrames מותקן).
- **לפחות שילוב אחד מקבוצה ו'** בהצעה, כדי שהמשתמש יראה גם כיוון שלם ולא רק חלקים.
- **בלי פנים:** cinematic, docu, motion, screen, ו"הבית (המותג שלך)".
- **לעולם לא** כל הסגנונות יחד. סגנון אחד מוביל, ושאר הסגנונות לסרטונים הבאים.
